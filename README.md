# TradeMatch - Stock Market Order Book Simulator

A modern Flask-based Stock Market Order Book Simulator that demonstrates how a real stock exchange matches buy and sell orders using Price-Time Priority.

---

## Features

- Buy Order Placement
- Sell Order Placement
- Price-Time Priority Matching
- Order Book Visualization
- Trade History
- Analytics Dashboard
- Responsive UI
- Pure Python Matching Engine
- Flask Backend
- HTML & CSS Frontend

---

## Technologies Used

- Python
- Flask
- HTML5
- CSS3

## Installation

Clone the repository

```bash
git clone https://github.com/karthikeyayadavdasari-45/tradematch-stock-market-order-book-simulator.git
```

Move into project

```bash
cd tradematch-stock-market-order-book-simulator
```

Create Virtual Environment

```bash
python -m venv .venv
```

Activate

Windows

```bash
.venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run

```bash
python app.py
```

Open

```
http://127.0.0.1:5000
```
